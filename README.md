# github_activity
This project aims to build a simple command line interface (CLI) to fetch the recent activity of a GitHub user and display it in the terminal.

This repo aims to provide a solution to the project on [roadmap.sh](https://roadmap.sh/), and here's the [project URL](https://roadmap.sh/projects/github-user-activity).
